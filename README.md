# Lupo Radar

Relevés publics des jeux Roblox (joueurs, visites, votes) toutes les 30 minutes, pour le radar de tendances de Lupo.
Les données sont publiées dans la release `donnees` (`etat.json`, `radar.db.gz`, `lot-*.db.gz`).

Le code de `radar/` est compilé depuis le logiciel Lupo (`npm run serveur-radar` dans `app/`) : ne pas le modifier ici.
